Cómo conectar cada plataforma
📷
Instagram / Facebook
1
Convertí tu cuenta a Negocio
En Instagram → Configuración → Cuenta → Cambiar a cuenta profesional
→ Guía oficial de Meta
2
Crear App en Meta for Developers
Creá una app de tipo "Negocio" y habilitá el producto Instagram Graph API
→ developers.facebook.com/apps → Documentación Instagram Graph API
3
Obtener Access Token de larga duración
Permisos necesarios: instagram_content_publish, pages_read_engagement
→ Graph API Explorer (generador de tokens) → Referencia de publicación de medios
4
Pegá tu token aquí
🎵
TikTok for Business
1
Registrate como desarrollador
Creá una cuenta de desarrollador con tu cuenta TikTok existente
→ developers.tiktok.com
2
Crear una App y solicitar Content Posting API
Requiere aprobación de TikTok (1-3 días hábiles)
→ Mis apps en TikTok for Developers → Content Posting API — documentación
3
Autorizar con OAuth 2.0
Obtené el access_token con scope: video.publish
→ Guía OAuth de TikTok → Guía de inicio rápido
4
Pegá tu token aquí
▶️
YouTube / Google
1
Crear proyecto en Google Cloud
Creá un proyecto nuevo y habilitá la YouTube Data API v3
→ Google Cloud Console → Activar YouTube Data API v3
2
Configurar pantalla de consentimiento OAuth
En APIs & Services → OAuth consent screen. Scope: youtube.upload
→ OAuth consent screen → Guía de autenticación OAuth
3
Crear credenciales OAuth 2.0
Generá Client ID + Client Secret y obtené el refresh_token
→ Crear credenciales OAuth → OAuth Playground (probá tu token aquí)
4
Pegá tu token aquí
